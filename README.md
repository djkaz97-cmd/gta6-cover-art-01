# Vice Cover

GTA-6-style cover art maker: turn your own photos and a caption into a multi-panel poster with a Vice City sunset/neon grade, exported as PNG in 1080x1080, 1080x1350 or 1920x1080.

## Run

Serve `app/` with any static server, e.g. `node serve.ts` or `python -m http.server 8080 --directory app`, then open http://localhost:8080. All assets are local; no network requests.
