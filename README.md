# Vice Cover — GTA 6 Cover Art Maker

GTA-6-style cover art maker: turn your own photos and a caption into a multi-panel poster
with a Vice City sunset/neon grade, bold caption lettering with outline and glow, neon
panel dividers and a VICE CITY tag, exported as a PNG in 1080 x 1080, 1080 x 1350 or
1920 x 1080.

## Run

Serve `app/` with any static server, e.g. `python -m http.server 8080 --directory app`, then open http://localhost:8080. All assets are local; the app makes no network request. Load one or more photos, pick a panel count, drag each photo inside its panel, edit the caption and click Export PNG to save the cover.
